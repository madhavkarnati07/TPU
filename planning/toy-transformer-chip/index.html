Toy Transformer Chip

An educational Tiny Tapeout ASIC that computes a complete fixed-shape, serialized self-attention operation with signed-int4 arithmetic.

Current System

The goal is to understand and physically realize a playful, inspectable chip that performs the core arithmetic behind a transformer in a very small, serialized form. The first complete version now works from the Python model through RTL, gate-level simulation, and 2x2 hardening.

  • Four 2D tokens, one attention head, and host-loaded Q/K/V projection weights.
  • Two reusable signed-int4 MAC lanes with signed-int16 accumulation.
  • Clipped-linear attention and a Q0.8 reciprocal LUT instead of exponential softmax.
  • Verified Tiny Tapeout byte protocol, 2x2 physical fit, and passing precheck.

Working Assumptions

Area Assumption
Platform Tiny Tapeout Sky130 digital design with the standard Verilog wrapper and byte-wide host I/O.
Arithmetic Use signed int4 operands, packed two per byte, with signed 16-bit accumulators.
Memory Use tiny on-chip operand/result registers for a fixed 4 x 2 toy attention example.
Transformer scope Target one serialized single-head attention pass with on-chip Q/K/V projection and clipped-linear normalization.
Implementation status Full attention RTL and wrapper pass source and powered gate simulation. The hardened 2x2 macro and Tiny Tapeout precheck pass locally.
