Requirements And Scope

A living requirements page for the educational toy transformer chip.

Primary Goal

Design a small chip that physically demonstrates the core arithmetic behind transformer computation, especially matrix multiplication and self-attention, without trying to be fast, dense, or useful for production inference.

Hard Requirements

  • The project must remain educational and inspectable.
  • The first implementable target must fit a Tiny Tapeout-style digital design.
  • The design should be simulatable before any tapeout submission work.
  • The host may stream operands, control sequencing, and store most intermediate state.
  • The chip should expose a simple byte-oriented protocol that can be tested from Python.
  • Prefer int4 as an early candidate if it lets the toy problem size feel more transformer-like.
  • The fixed Phase 2 target is a simple serialized single-head attention pass with on-chip Q/K/V projection.

Explicit Non-Goals

  • No standalone LLM or useful transformer inference on-chip.
  • No large on-chip SRAM requirement in the first design.
  • No exact softmax requirement; approximation, simplification, or host assistance are acceptable.
  • Avoid optimization-driven complexity unless it is needed for basic feasibility.
  • No RTL implementation until protocol, datapath schedule, numeric rounding, and verification plan are approved.

Success Criteria

Draft

Simulation success

A Python golden model and RTL simulation agree on small int arithmetic examples.

Draft

Concept success

The chip can explainably compute at least one matrix or attention-like primitive.

Draft

Tapeout readiness

The final selected design can pass Tiny Tapeout hardening and gate-level simulation.
