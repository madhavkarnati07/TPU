Prototyping Plan

Lower-level verification details under the top-down design roadmap.

Stage 1: Python/Numpy Golden Model

Define the exact toy computation in Python first. This should include signed integer behavior, saturation or wrap rules, input ordering, and expected output bytes.

Stage 2: RTL Design Review

Before simulation, review the planned Verilog module boundaries, FSM, byte protocol, accumulator behavior, and reset behavior. This stage is still design review, not coding.

Stage 3: RTL Simulation

Use cocotb with Icarus Verilog as the first practical simulator loop. Tests should drive the same byte protocol that a Tiny Tapeout demo board or host script would drive.

Stage 4: Waveform Review

Use GTKWave or Surfer to inspect reset, load, compute, output valid, accumulator state, and protocol timing. This is an educational deliverable, not just a debug aid.

Stage 5: Tiny Tapeout Flow

Once the design is stable, move into a Tiny Tapeout template, harden the design, run gate-level simulation, and prepare the submission package.
