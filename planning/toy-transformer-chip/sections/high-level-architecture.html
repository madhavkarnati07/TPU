High-Level Chip Architecture

Implemented specification for the fixed-shape toy-attention chip.

Specification

Area Decision
Demo target One serialized single-head attention pass.
Toy shape N = 4 tokens, D_IN = 2, D_QKV = 2, one head.
Arithmetic Signed int4 operands, two packed per byte; signed 16-bit accumulators.
Q/K/V The chip computes Q, K, and V projections from loaded X, Wq, Wk, and Wv.
Scores Use raw integer QK^T scores in the first hardware contract.
Softmax substitute Clipped-linear weights with B = 4, then Q0.8 reciprocal-LUT normalization.
Core primitive Two reusable signed-int4 MAC lanes with signed-int16 accumulators.

Reading The Diagram

Block Meaning RTL realization
Host byte stream The outside controller sends one byte at a time into the chip: commands, packed int4 operands, and debug selectors. ui_in plus uio_in[0] valid and uio_out[4] ready.
Command FSM The chip's control brain. It decides whether the current byte is a command or payload, counts bytes, starts compute, and starts drain. A Verilog case over ten states from COMMAND through TX.
Operand registers Tiny on-chip storage for the values the chip needs while computing: X, weights, Q/K/V, one score row, and results. Small register arrays, not a large SRAM.
Int4 unpack Each input byte carries two signed int4 numbers. This block splits the byte into two nibbles and sign-extends them before math. Combinational wires/helpers around the MAC inputs.
MAC + int16 accumulator Two lanes each multiply signed int4 values and add into a signed 16-bit sum. Both lanes run in parallel for Q/K/V and weighted V; lane 0 handles serialized scores.
Clamp / pack Convert wider results back to signed int4 using saturation, then pack two int4 values into one output byte. Small saturation and packing logic.
Output byte stream The chip returns result or debug bytes to the host one byte at a time. Output mux plus valid/done signaling.

Execution Steps

This section is the algorithm contract for the chip. The specification says what the design is; these steps say what the chip must do in order before we assign clocks and RTL states.

Stage Chip Work Result
Load Accept packed int4 bytes for X, Wq, Wk, and Wv. Small operand registers are ready.
Project Q/K/V For each token and output dimension, run a 2-wide int4 dot product. Q, K, and V are stored as int4 matrices.
Score row For one query token, dot its Q vector with all four K vectors. Four signed 16-bit scores for one attention row.
Clip weights Find row max, then compute u_j = max(0, 4 + score_j - max_score). Four small weights in range 0..4.
Weighted V Accumulate sum(u_j * V_j) for each output dimension and sum_u for the row. Two numerators plus one denominator.
Normalize Read Q0.8 reciprocal[sum_u], multiply, round-to-nearest, shift, and saturate to int4. One output token vector.
Drain Pack final int4 outputs into bytes; optionally drain debug values in a separate mode. Host receives the final toy attention result.

State Budget

Object Implemented size Notes
X 4 x 2 int4 = 4 bytes Input token embeddings.
Wq, Wk, Wv 3 x 2 x 2 int4 = 6 bytes Projection weights loaded by host.
Q, K, V 3 x 4 x 2 int4 = 12 bytes Stored after projection so attention can run without host round trips.
Score row 4 signed int16 = 8 bytes Only one row is needed at a time.
Weight row 4 values in 0..4 Can be held as nibbles or tiny registers.
Accumulators Two signed-int16 MAC sums, two signed-int16 numerator registers, and a 5-bit denominator The same two MAC sums are reused across phases.
Result 4 x 2 int4 = 4 bytes Stored before the host issues READ_RESULT.

The packed operands, projections, row scratch, numerators, results, and MAC sums account for about 42 bytes of logical data state. The hardened core contains 446 flip-flops after adding the FSM, counters, handshake state, and synthesis realization.

Byte Protocol

A transfer occurs on a rising edge when valid and ready are both high. The RTL holds an output byte stable while tx_valid=1 and tx_ready=0.

Command Payload Effect
LOAD_X (0x10) 4 packed bytes Load the 4 x 2 input embedding matrix.
LOAD_WQ (0x11) 2 packed bytes Load the 2 x 2 Q projection matrix.
LOAD_WK (0x12) 2 packed bytes Load the 2 x 2 K projection matrix.
LOAD_WV (0x13) 2 packed bytes Load the 2 x 2 V projection matrix.
RUN_ATTENTION (0x20) None Compute Q/K/V and all four output token vectors.
READ_RESULT (0x30) None Drain 4 packed result bytes.
READ_DEBUG (0x31) Debug selector Required observability path: drain Q/K/V, score rows, clipped weights, sum_u, or intermediate accumulators for learning and test comparison.
FLUSH (0xff) None Return to command mode, clear status, and invalidate all loaded operands.

Controller States

Controller states are needed because hardware runs one clock at a time. The chip must remember whether it is loading bytes, computing a dot product, normalizing attention, draining output, or serving a debug read. That memory is the finite-state machine.

State Purpose Exit
COMMAND Wait for command byte. Valid command arrives.
LOAD Count payload bytes and fill the selected register region. Expected byte count received.
PROJECT Use both MAC lanes for all Q/K/V dot products. All projection entries computed and clamped.
SCORE Use MAC lane 0 to compute four QK^T scores for the current query token. Four row scores are available.
MAX Scan the four score registers for the row maximum. The maximum is stored.
CLIP Derive clipped-linear weights and accumulate their denominator. u row and sum_u are available.
WEIGHT Use both MAC lanes to accumulate weighted V numerators. Both output dimensions have numerators.
NORM Apply Q0.8 reciprocal LUT, round-to-nearest, and int4 saturation. Current output token is stored.
DEBUG Accept and validate one debug selector. A response kind and length are selected, or protocol error is set.
TX Emit result or debug bytes with ready/valid backpressure. Requested bytes have been emitted.

Numeric Rules

Rule Decision Meaning
Reciprocal LUT Q0.8 Store round(256 / sum_u) for valid denominators.
Normalization rounding Round-to-nearest, ties away from zero, before the final shift. Python and RTL use the same signed rule for positive and negative products.
Int4 clamp Saturate to signed int4 range [-8, 7]. Values above 7 become 7; values below -8 become -8. Do not wrap.

Debug Readback

READ_DEBUG stays in the architecture. It is not needed for the chip to compute the final answer, but it makes the chip inspectable: the host can ask for intermediate values and compare them against the Python model without relying only on waveforms.

  • Useful during simulation: compare Q/K/V, score rows, clipped weights, sum_u, and numerators.
  • Useful for demos: show the attention computation step by step from a real chip.
  • Implemented as selectors 0x00 through 0x08 and verified at RTL and gate level.

Why It Matters

The FSM must know where the next bytes should be stored.

Q/K/V and weighted V use both lanes. Score rows use lane 0 because the compact Q/K storage exposes one score operand pair at a time.
